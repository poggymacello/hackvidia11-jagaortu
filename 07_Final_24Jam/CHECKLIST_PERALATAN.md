# Checklist peralatan & persiapan final (29–31 Jan 2027, ITB)

Cek H-7 (22 Jan), H-1 (28 Jan), dan saat berangkat. ☐ = belum, ☑ = sudah.

## Perangkat demo
- ☐ **3 HP Android** (Ibu, Rina, Penipu); minimal HP-IBU Android 13–15. Catat versi Android masing-masing.
- ☐ 1 HP Android cadangan untuk peran Ibu (kalau HP-IBU rusak)
- ☐ SIM aktif + **paket data** di HP-IBU dan HP-PENIPU (2 operator berbeda) + pulsa SMS
- ☐ WhatsApp terpasang & terverifikasi di HP-IBU dan HP-PENIPU (nomor HP-PENIPU **tidak** tersimpan di HP-IBU)
- ☐ Kabel data USB per HP + adaptor USB-C/USB-A
- ☐ Opsi developer + USB debugging aktif di HP-IBU (untuk pasang APK & mirroring)
- ☐ Stiker label "IBU / RINA / PENIPU" di casing
- ☐ Penyangga HP / kamera dokumen (atau aplikasi mirroring layar yang sudah diuji) untuk memperlihatkan 2 HP ke proyektor
- ☐ Speaker kecil Bluetooth (supaya suara peringatan HP-IBU terdengar juri), sudah dipasangkan

## Laptop & jaringan
- ☐ Laptop per anggota + charger. Minimal 1 laptop bisa build Android (Android Studio + SDK + JDK terpasang & sudah diuji **sebelum** final; ini perangkat, bukan kode)
- ☐ Python 3.11+, Node/npm (bila dipakai), Git, editor; login GitHub di semua laptop
- ☐ **Modem/HP hotspot cadangan** ×2 (operator berbeda) + kuota besar
- ☐ Terminal listrik / colokan T (minimal 4 lubang) + kabel roll 5 m
- ☐ Power bank ×2 (≥10.000 mAh)
- ☐ Adaptor HDMI/USB-C ke HDMI (untuk proyektor) + kabel HDMI
- ☐ Flashdisk berisi: deck PDF, video demo, APK terakhir, dokumen proposal

## Akun & kunci (siapkan sebelum, simpan aman; jangan di-commit)
- ☐ Akun GitHub semua anggota; tahu cara mengundang akun panitia ke repo (Settings → Collaborators)
- ☐ API LLM utama + cadangan: kuota/billing aktif, batas pengeluaran diset
- ☐ Layanan TTS (suara id-ID & su-ID) aktif
- ☐ Hosting backend HTTPS (akun aktif, region dekat)
- ☐ (Bila dipakai) Firebase/Web Push: proyek dibuat, kunci VAPID siap
- ☐ Password manager bersama untuk kunci (bukan grup chat)

## Bahan non-kode (boleh disiapkan; konfirmasi ke panitia saat technical meeting)
- ☐ Dataset pesan uji berlabel (CSV: teks, label, sumber) ±100–300 pesan, termasuk ≥20 Sunda/Jawa yang dicek penutur asli
- ☐ 3 pesan demo (lihat `DEMO_SKENARIO.md`)
- ☐ Rekaman frasa peringatan bahasa Sunda oleh penutur asli (opsional, aset milik sendiri)
- ☐ Ikon/ilustrasi berlisensi terbuka + catatan lisensinya
- ☐ Kerangka deck (tanpa angka hasil demo) + bank Q&A dicetak
- ☐ Hasil riset pengguna (folder 06) + 1–2 foto sesi wawancara (dengan izin, tanpa wajah bila tidak diizinkan)

## Pribadi (24 jam karantina)
- ☐ KTM + KTP (registrasi ulang)
- ☐ Jaket / selimut tipis, bantal leher, sikat gigi, obat pribadi
- ☐ Air minum, camilan, kopi/teh (cek aturan makanan panitia)
- ☐ Earplug + penutup mata (tidur bergilir)
- ☐ Pakaian rapi untuk pitching & awarding night (31 Jan, **wajib hadir**)
- ☐ Alat tulis, kertas A4 untuk sketsa, spidol, sticky notes
